# Scope

InkForge is a local-first desktop writing tool for solo novel authors.

## In Scope

- Local project folders.
- Markdown chapters and JSON metadata.
- Outline, volume, chapter, character, worldbuilding, timeline, clue and term management.
- User-triggered OpenAI-compatible model calls through the Electron main process.
- Draft-first AI outputs that require author confirmation before changing source files.
- Markdown, TXT and DOCX export.

## Out of Scope

- Login, cloud sync, SaaS billing, memberships or ads.
- Team collaboration, permissions, comments or approval workflows.
- Platform publishing community features.
- Auto-generated gray-area rewriting or review-evasion tooling.
- Renderer-side API key storage.
