## 已完成

- 最终 CPT adapter 的 SHA256 与此前验收一致；新脚本固定加载 `runs/cpt-final/adapter`，不使用旧脚本里的 `cpt-v1`，不覆盖 CPT。
- 重新验证现有标注：558/586批通过结构和来源校验，缺28批；7,194个chunk中1,262个带质量旗标。没有把模型自报置信度当成语义验收。
- 严格筛选后冻结3,709条候选：训练3,335、验证162、测试212。排除有旗标、质量评分不足、原文疑点、过短目标或同单元内无可用前文的样本；原文不改，人物名和地名不替换。
- 前文均来自目标之前、同一来源单元与split；章节组互斥。目标段中的前置条件、实体和证据未自动变成历史正典。目标派生的写作要求明确作为作者计划。
- `packages/prompt-engine/src/writer.ts` 提供确定性的 `buildWriterMessages` 和 `inkforge.writer.v1` 输入类型。训练导出实际调用这一实现，已逐条复现3,709个请求；应用当前生成入口仍使用旧renderer，尚未接入新函数，不能声称训练/应用端已全部对齐。
- 云端用固定 Qwen 官方模板完成编码。提示与非思考前缀全部mask，loss只作用于正文和 `<|im_end|>`；不截断、不跨样本packing。tokenizer和模板哈希已保存。

## 试训数据

完整阅读12条原文样本及其前文、目标和写作要求，接受9条，隔离3条（错字、残缺句与否定关系歧义），理由保存在 `pilot-semantic-reviews.json`。此范围不能冒充已完成100条抽查。

新增8条原创约束样本，覆盖资源不足、预付款/尾款、唯一物品、能力限制、人物知识时点、消耗数量和守卫位置。这些由本轮主助手创作并自查，未调用外部教师模型，不是独立盲审。未使用之前盐窟/黑市的人工改稿作为训练答案。

试训合计17条：12训练、5验证；总长度1,060–1,405 token。训练集只有12条，20步会重复看到这些样本；用途是检验训练链、显存、吞吐和初步退化情况，不能据此证明泛化或逻辑已修好。

已经冻结8个新世界观评测请求，另保留此前两题已知失败回归。评测没有参考正文，不导出为训练目标。检查账目、物品、实力、知识、位置与能力约束，并另评文风、重复和大模型编辑工作量；已知失败题不算盲测。

## 启动配置与限制

| 参数                   | 首轮技术试训                                  |
| ---------------------- | --------------------------------------------- |
| 继承权重               | 最终 CPT，rank16 LoRA                         |
| 精度                   | BF16，不做4-bit训练                           |
| 长度上限               | 4096，真实试训样本远短于此值                  |
| 学习率                 | 1e-5                                          |
| micro batch / 梯度累积 | 1 / 4                                         |
| 步数                   | 20 optimizer steps                            |
| 评估与保存             | 每10步，保留2个checkpoint                     |
| 运行上限               | 1500秒，含加载和保存                          |
| 计算费上限             | 按2.88元/小时折算1.20元；不含准备、空闲和存储 |
| 提升判断               | 不自动按loss推广为生产writer                  |

云端数据预检、父权重哈希、源组互斥、文件校验和、正文mask与shell语法均通过。尚未实际加载模型进行梯度更新，因此显存、吞吐、运行时LoRA张量匹配仍须由首轮试训验证。启动代码会在更新前核对父adapter的实际加载张量，发现漂移立即停止。
