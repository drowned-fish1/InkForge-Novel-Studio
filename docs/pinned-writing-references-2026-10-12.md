# 固定写作资料卡实现与验收

2026-10-12。沿用工作区已有“资料速查”和预览点击入口，补全固定资料卡；未增加依赖、模型调用或新的小说数据存储。

- 写作速查支持固定人物、术语、世界观、地点和势力。人物、世界观和术语库提供“固定到写作台”，固定已保存条目；不自动保存正在编辑的表单。
- 最多六张，可激活、收起、移除单卡与关闭全部；跨章节／模块和本机重开记住。偏好按项目路径隔离，仅保存 kind、ID、活动卡和收起状态，失败时明确报错。
- 内容实时从当前项目资料库读取，不存字段快照。世界观／地点／势力共享实体 ID，分类变化不会产生重复卡。删除目标显示失效，不替换成不相关资料。
- 编辑器保持在同一 DOM 槽位：固定卡宽屏并排，正文区低于 760px 时在下方。固定操作保留正文、选区与编辑器实例；预览中固定保持预览页签。
- 同名／共享别名的预览标记打开候选列表，作者选定后才可固定；搜索精确名称优先于正文描述命中。
- 当前人物状态标明来自资料库，不声称已经做章节历史回溯。固定卡与 AI 的资料固定／排除是独立设置。
- 资料库记录加载所属项目路径，迟到的其他项目加载结果不覆盖当前数据；参考面板在项目资料加载完成前显示读取状态。

## 验证

- 全量 76 个测试文件、469 项测试通过。本功能增加 8 项，检查同名选择、名称优先级、偏好解析／去重／上限、保存重开、项目隔离、删除活动卡和存储失败。
- Renderer／Electron 类型检查、相关文件 ESLint、Prettier 和 diff 空白检查通过。
- Playwright 在独立浏览器样本项目验证：速查固定、切换、重复固定、收起／展开、跨章节、预览点击与共享别名选择、刷新重开、资料库三个按钮、保存后更新、未保存字段不进卡、删除资料提示、同 ID 跨项目隔离、单卡移除和关闭全部。
- 验证固定时正文编辑器 DOM 未重新挂载，选中五字不丢，正文内容不变。浅色／深色、1000px 和 650px 窗口截图已检查，650px 下参考区位于编辑器下方且无横向溢出。

截图及浏览器脚本位于忽略的 `output/playwright/pinned-reference-*`。未验证安装器和原生操作系统弹窗。本机固定偏好不随项目文件备份／迁移，另一章或大纲参考与正文写作视图的自动姓名标记仍属于后续范围。

主要实现：`WritingReferencePanel`、`WritingReferenceCard`、`PinnedWritingReferences`、`PinWritingReferenceButton`、`writingReferences`、`useWritingReferenceStore` 与 `pinnedWritingReferences.css`。
