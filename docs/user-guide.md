# InkForge 用户指南（v1.0 RC）

InkForge 是本地优先的小说创作工作台：所有数据保存在你自己的项目文件夹里；
不配置 API Key 时，写作、资料、修订、备份和导出全部可用；配置后可启用 Agent 辅助，
但所有写入都要经过你的确认。

## 开始

- **创建小说**：启动页输入书名即可；也可以“导入项目文件夹”，或从 Word .docx、EPUB 2/3、.md、.txt 文稿建项目。
- **导入 EPUB**：选择或拖入 `.epub` 后，应用会按书内阅读顺序解析章节，并自动带入书名和作者；确认预览后再创建项目。
- **打开失败？** 如果项目文件损坏，启动页会列出该文件夹内的备份快照，选择一个恢复后重新打开。

### 旧稿迁移

选择或拖入文件 / 文件夹，应用按文件名的自然顺序读取。Word 保留标题、正文和常用强调格式；中文“第 X 卷 / 部”“第 X 章 / 节 / 回”、英文 Chapter，以及 Markdown / Word 标题用于分卷拆章。没有章节标题时，整份文件作为一章，前言正文会保留。

TXT / Markdown 自动尝试 UTF-8、带 BOM 的 UTF-16 和 GB18030；遇到乱码可手动选编码。可选择自动拆章、一级 / 二级标题或每文件一章，修改规则后点“重新解析 / 重置预览”。EPUB 沿用阅读顺序和原有章节解析，不受文本拆章选项影响。

选中预览章节后，可改标题、所属卷、正文，上移 / 下移、在正文光标处拆章、合并下一章或移除章节。重新解析可撤销预览调整；确认后创建新的项目与分卷，不改动源文稿。所属卷按章节顺序分组，相邻同名卷合并。

旧版 `.doc` 需先另存为 `.docx`。Word 插图保留占位文字；页面排版、批注、修订记录不迁移。文本 / Word 单文件上限 64 MB，Word 解压体积也有限制；超大文稿请拆成多个文件导入。

### 整书人物 / 支线 / 视角矩阵

在左侧“剧情 → 整书矩阵”切换人物、支线 / 伏笔、视角三个页签，可按卷与名称筛选、仅显示关联行，并导出当前筛选结果为 CSV。人物列固定，长书的行与章节列按需渲染。点击格子或用方向键后按 Enter 查看来源，可打开章节或定位原文。

人物矩阵汇总章节人物规划、场景人物 / 视角和时间线事件。勾选“扫描正文提及”后，用现有人物库的姓名 / 别名扫描本地正文，不调用模型；提及次数不等于人物实际出场，同名或重复别名不会自动归给某个人。

支线矩阵复用续写工程的剧情线证据、伏笔埋设与场景关联、冲突的关联章节。铺垫、推进、回收分开展示；预计回收窗口使用“预计”标签，不计为已推进或已回收。已经迁移成剧情线的旧伏笔只显示一行。

视角取自“章节辅助 → 场景规划”的“视角人物”，支持一章多视角；未标注、人物引用失效或场景读取失败都会显示待补。可在同一处选择场景人物，之后刷新矩阵。归档章节不参加矩阵；整书覆盖与最长间隔来自关联记录，间隔包括最后一次关联后的章节，不包括第一次关联之前。

### 固定资料卡

在写作台点“查资料”，可搜索人物、别名、术语、世界观、地点和势力，选择条目后点“固定这张资料卡”。人物、世界观和术语页面也提供“固定到写作台”；新资料需先保存，正在编辑但未保存的字段不会写入固定卡。

最多固定六张，点击卡片名称切换，名称旁的 × 取消单张固定，面板右上角可收起、展开或关闭全部固定卡。固定状态跨章节和模块保留，在本机按项目路径记住，重新打开项目也会恢复。宽的正文区显示在旁边，正文区变窄时移到下方；固定、切换或收起不会重新创建正文编辑器。

正文预览里的姓名、别名或术语可直接点开速查，再固定。多个条目使用同一姓名或别名时先显示候选，需作者选择；精确名称优先于资料内容里的提及。固定预览中的卡片会保持预览页签。

卡片只读引用资料库已保存内容，保存资料修改后同步更新；删除资料会提示失效，可移除固定记录。“打开完整资料”进入原资料编辑页，返回写作台后固定卡仍在。人物动态状态展示资料库当前记录，尚未按正在写的章节回溯。

固定偏好存放在本机界面设置中，不复制人物／世界观正文，也不改变 AI 上下文资料选择。换项目不会混入另一书的卡；移动项目路径或换电脑需重新固定。本轮固定的是资料条目，另一章正文和大纲参考窗尚未加入。

## 写作（章节写作台）

- 左侧章节树管理分卷与章节（拖拽排序、归档、删除）；`Ctrl+1` 快速回到写作台。
- 工具栏：查找替换（`Ctrl+F`）、标题下拉跳转、加粗/斜体（正文内 `Ctrl+B` / `Ctrl+I`）、
  引用段落、打字机滚动开关。
- 选中文字后可创建**批注**或**待修改标记**；光标处可加**书签**；
  在“章节辅助 → 批注书签”里跳转、解决或删除。
- “写作统计”页签显示今日字数/时长、本章进度和最近 7 天记录（全部来自本机会话）。
- 专注写作（`Ctrl+B`，编辑器外）提供段落聚焦与居中滚动；`Esc` 退出。
- 自动保存 + 崩溃恢复草稿；“历史版本”页签可预览并恢复每次覆盖前的正文。
- 右上角机器人按钮可收起/展开 Agent 面板，状态会被记住。

### 选中文字加入对话

在正文编辑器中选中文字，点击工具栏“加入对话”。Agent 面板会自动展开，输入框上方显示“1 条引用”等计数；点击计数可查看所选原文和来源章节，使用铅笔按钮补充针对该段的批注，或删除单条/全部引用。可以继续选择其他段落，一次最多附加 8 条引用，同一位置的相同文本不会重复添加。

在消息框输入整体要求后发送，所选原文、来源位置及批注会一起交给 Agent。引用本身不会修改正文；修改仍使用既有提案流程及当前项目的 YOLO 设置。引用属于选取时的原文，后续编辑可能改变其位置，Agent 会被要求在修改前核对当前正文。

引用按项目和来源章节隔离，收起面板或切换章节不会把它们附到其他章节的消息里；回到原章可继续使用。成功发送后清空本轮引用，请求失败或取消时恢复到输入区。待发送引用仅保留在当前应用会话中，不随项目保存，重启后需重新选择。

## 故事资料

- **人物 / 世界观 / 地点 / 势力 / 术语**：完整增删改查与搜索；地点与势力保存为世界观条目的
  对应类型，与其他模块共用同一数据。
- **冲突**：主线/支线/人物/势力冲突，记录各方、赌注、状态并关联章节。
- **事件**：与时间线共用数据，支持章节关联、参与人物与发生地点。
- **关系**：关系中心汇总全部实体（含章节）的关联；选中节点查看“引用了 / 被引用”双向列表。
- **删除保护**：删除任何资料前会列出所有引用，可取消、一键解除全部引用，或替换为新名称。

## 修订工作台

汇总五类待办：批注、待修改标记、本地质量问题、连续性问题、Agent 提案（跨章节）。
支持来源/状态/章节筛选、排序、批量接受/忽略/延期、恢复为待处理；
提案可先看前后行级差异，应用后自动重算该章质量分并显示与基线的差值。

## 备份与草稿

- **备份**：自动快照（间隔/保留数量/磁盘上限可设，支持项目外备份目录）；
  每个快照记录变更章节并可做完整性校验；恢复前展示逐章差异，恢复时自动创建回滚保护点。
- **草稿箱**：按状态筛选章节，多选后批量归档/恢复/改状态/移动分卷；
  “历史版本”页签跨章节聚合全部历史并提供差异预览；“灵感片段”保存不属于章节树的素材，
  可一键转为章节。

### 每日模板与存稿管理

在“写作 → 草稿箱”里打开“每日模板”。内置日更一章、双更冲刺和轻量写作，可调整字数、分钟、每日发布字数与待办，再保存当日计划；也可取名后“另存为模板”。模板会成为后续未安排日期的默认计划。每天单独保存目标与待办完成状态，修改模板或删除自定义模板不会改写已保存日期的计划。切换模板保留同名待办的勾选，换到新日期则重新开始。

日期选择器和近七天记录可返回某日。全书完稿期限为项目设置，预计完稿按当前日目标与剩余总字数估算，连续写作并达到目标是估算前提；存稿天数按未发布可用字数除以每日发布字数取整。发布量填 0 时不估算更新天数。计划中的目标、待办与期限需点“保存当日计划”或 `Ctrl+S`，离开未保存表单会提醒。“章节辅助 → 写作统计”也显示已设置的日目标进度。

“存稿管理”里，已完成且有正文的非归档章节默认计入存稿；可将其他非空章节标为可发布存稿。支持按状态或章节名筛选、批量标记存稿／已发布／移出存稿，以及逐章设置计划或实际发布日期。修改日期后点“保存排期”或“更新记录”，也可 `Ctrl+S` 批量保存；到期排期需实际更新后手动标为已发布。空章节不能标为可发布。已发布章记录当时字数，修改正文后可看到字数变化提示；调整发布日期保留原发布字数。撤销发布清除该章发布信息。

每日计划、模板与发布记录复用项目的 `.inkforge/writing-workspace.json`，并随现有项目备份保存。字数与时长复用写作会话：统计已结束会话的净字数增长和编辑页面停留时间，按会话开始日期归属；导入正文和未打开编辑器的修改不计入日字数。写作统计页另外包括当前会话。浏览器预览保存于该浏览器本地存储，桌面版写入项目文件。

### AI 人物卡与起名

在“资料 → 人物”打开“AI 人物卡／起名”。给新角色生成时，先点“新角色”；也可给当前人物补全资料。使用“故事规划”用途的模型；未单独配置该用途时继承默认模型。此入口复用现有模型请求，不需要支持工具调用。

起名可指定姓氏（含复姓）、性别倾向、命名文化、全名长度、避用字和人物设想。“只生成名字”提供名字、寓意与适配理由；本地检查全库姓名及别名重名、指定姓氏、长度和避用字，不合格候选会标记原因并禁止采用。性别倾向、文化与气质由模型参考，作者自行判断。“采用这个名字”只填入姓名。

“生成整张人物卡”同时返回候选名与身份、年龄、动机、性格、成长线、能力、位置、关系、秘密及口吻等预览。可选择“仅补空字段”保留已填内容，或“用整卡替换表单”；已有卡的 ID 保持不变。采用后可继续编辑，最后点“保存人物卡”。生成错误、JSON 格式不完整或停止生成时，之前的候选与人物表单保留；换人物或关闭生成面板会取消请求。

新项目包含 `prompts/character-names.prompt.json` 和 `prompts/character-generate.prompt.json`，可按小说调整提示词；旧项目缺少这些文件时使用内置默认提示词。

## Agent（可选，需要配置模型）

- 在 Agent 面板“模型设置”里配置 OpenAI 兼容 Provider；可选填写每百万 Token 单价，
  发送前会显示输入/输出 Token 与费用估算（明确标注为估算值）。
- “模型用途”可选择默认连接、正文写手、故事规划、审阅编辑和工具 Agent。
  未勾选“单独配置此用途”时继承默认连接；勾选后可分别填写地址、模型、鉴权、
  Temperature、最大输出 Token 和价格。续写工程和创作组的正文阶段使用写手，
  大纲与推演使用规划，检查与编辑使用审阅，工具聊天使用 Agent。
  Agent 成员的模型名覆盖只改变该阶段所选连接的模型，不改变地址或凭据。
- “InkForge 9B 写手”预设填写本机 `http://127.0.0.1:8000/v1`，关闭工具调用。
  请先启动兼容服务，并把模型名改为服务实际提供的名称；预设不会下载或加载模型。
  只有本地写手时可以先保存它，默认云连接缺少 Key 会保持未配置状态。
- Key 留空保留该连接已有的密钥；更换地址或鉴权方式后需要重新填写，密钥不会在用途间继承。
  桌面版通过系统安全存储加密，浏览器预览仍使用浏览器本地存储。
  取消单独配置并保存后，该用途恢复继承默认连接。
- “保存并探测当前用途”先验证文本生成，再检查允许的工具能力。
  工具探测失败不会把文本服务判定为不可用；流式能力在实际生成时验证。
  单独配置的用途遵守自身最大输出额度，正文模型可以设置低于 4096 的额度。
  同地址编辑模型为旧配置兼容选项，单独配置审阅编辑后优先使用该用途的模型。
- 工具权限支持逐工具“每次询问”：勾选后每次调用前都会弹卡片等你允许/拒绝，
  决策记录在“运行追踪”里。
- 普通模式下，正文、资料和大纲修改生成**提案**，接受后写入；YOLO 会自动应用本轮新提案；
  “资料”按钮可导入文本文档作为素材；上下文面板可排除不想让 Agent 读取的资料。
- 常用输入可“存为模板”；提示词包、任务模板和工作流模板都能随扩展 JSON 导入导出。

### 本书专属资料

每个项目独立保存 `project-data.json`，栏目和 JSON 内容按这本书自行组织。可以记录本书的人物、货币、装备、蛊虫、技能、系统规则等，不要求所有小说使用相同字段。

在项目内 Agent 中输入「根据现有设定和正文整理本书专属资料，缺失内容标记未知」，Agent 可用 `get_project_data` 读取、用 `propose_project_data_update` 提出新建或修改。后续可直接要求「修改陆砚的钱袋记录」或「删除旧技能栏目」。在提案中查看原内容和新内容，确认后保存；放弃不改数据。更新遇到版本冲突时重新生成提案，避免覆盖别的章节刚补充的内容。

写作和审阅按相关性及输入预算读取完整栏目。动态状态标注来源章节；修改历史保存旧值、新值及发生章节，旧章节上下文会撤销后续状态。Agent 可用 `get_project_data` 的 `historyOffset` 分页查看历史。没有发生章节或原句定位的信息不能精确还原故事时间。专属资料及历史随项目备份保存。

默认资料员和导演可提议修改，作家和编辑可读取；可在成员工具权限中调整。需要工具调用能力的模型负责维护资料，9B 正文模型读取传入的内容即可。浏览器预览的 Agent 仍为交互演示，真实资料工具在桌面版执行。

### 逻辑编辑、资料更新和 YOLO

续写工程默认使用「写手草稿 → 逻辑编辑 → 独立复核 → 分支」。编辑可以依据原文纠正错误数字或归属；复核失败、编辑响应无效时保留已有结果，不自动退回原稿放行。运行结果可查看原稿、修订稿、修改理由、Token、耗时和原段落保留率，也可下载包含完整写手输入的 JSON。

Agent 工具栏及续写页面的 YOLO 开关按项目保存，默认关闭。开启即生效，无开启确认弹窗；本轮工具不再逐次审批，新正文和资料提案自动应用。历史待处理提案保持原样。写入前保存项目备份；版本冲突、失效正文引用或续写硬检查失败时停止写入。计划模式继续只生成计划，A/B 模式继续只生成比较稿。恢复可在项目备份页面操作。

「更新资料」开启后，只在接受正文时调用资料维护 Agent，生成本书独有的数据变化，每项变化附实际原句、哈希及偏移。普通模式留下资料候选，YOLO 自动应用。抽取失败会提示重试，已接受正文仍保留；正文索引也会增量更新。原句匹配不等于语义判断一定正确，可继续要求 Agent 删改资料。

Provider 的「部署协议与输入窗口」可填写上下文窗口、停止字符串、模型/Tokenizer/聊天模板版本。完整消息与输出预留超过估算窗口时会在请求前阻止发送。该检查使用 CJK 估算；精确分词、服务端模板与结束符需要实际部署验收。价格按连接填写，缺少价格或用量时不显示虚构成本。

生成、重新生成、接受正文及 Agent 操作会先保存并核对当前章节；保存失败或保存期间切章、编辑正文时停止。编辑稿默认至少保留原稿一半字符，严重删减会阻断 YOLO 写入；确实需要缩稿时可在续写页面勾选「允许编辑压缩正文」，独立复核仍保留。

写手会按最终消息预算去除重复前文，并优先移除可选文风、检索证据和资料条目。锁定事实、人物状态和必要剧情线不会因窗口不足被静默删除；装不下时提示调整配置或拆分场景。续写还会为独立编辑连接预留正文空间。

读取资料时会检查原句是否仍存在。改写或删除的引用不进入有效上下文；锁定事实的引用失效会停止生成。全文变化但原句仍匹配时保留引用，并在运行卡片「资料来源提醒」中提示核对语义。保存的资料和历史不会因此删除。

续写记录首次读取时会从旧 `runs.json` 迁移到 `.inkforge/continuation/index.json` 与 `records/`，旧文件保留。每个检查点仅更新当前记录及索引；列表展示最近 100 轮，旧记录继续保留，项目备份包含新格式。

### 三条生成流程对照

从续写运行中下载 JSON 后，准备独立端点配置文件，执行：

```powershell
npm run build
node scripts/compare-writer.mjs --config endpoints.json --input continuation-run.json --output comparison.json
```

`endpoints.json` 格式如下，认证密钥使用环境变量，不放进报告：

```json
{
  "writer": {
    "providerId": "local",
    "displayName": "9B",
    "baseUrl": "http://127.0.0.1:8000/v1",
    "model": "inkforge-writer-9b",
    "authMode": "none",
    "temperature": 0.6,
    "maxTokens": 1024
  },
  "reviewer": {
    "providerId": "custom",
    "displayName": "审阅模型",
    "baseUrl": "https://your-endpoint.example/v1",
    "model": "your-model",
    "authMode": "bearer",
    "apiKeyEnv": "INKFORGE_REVIEWER_KEY",
    "temperature": 0.6,
    "maxTokens": 4096
  }
}
```

工具实际请求配置的模型，比较写手原稿、同稿经过编辑，以及审阅连接作为通用写手的正文；三者共用输入。报告保存正文、独立模型评估、生产 Token/延迟/估算成本，评估调用用量另列。模型评估仍需作者审核，作者接受率留空，不伪造质量提升结论。工具不修改项目，也不覆盖已有报告。

## 导出

- 顶栏“导出”支持 Markdown / TXT / DOCX / EPUB 快捷导出；“导出”页面提供完整配置：
  书名、作者、语言、简介、出版方、版权声明、封面（JPG/PNG）、样式主题、行距、段首缩进、
  分卷单独成页、是否包含分卷/章节标题。配置随项目保存。
- “导出前检查”会找出空章节、重复标题、会被移除的链接和缺失资源；
  EPUB 在有错误时会阻止导出，生成后还会做结构与 XHTML 校验。
- “导出预览”显示将要生成的目录结构与字数。
