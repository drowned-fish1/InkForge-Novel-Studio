# InkForge v1.0.0-rc.2 发布说明

RC2 是进入 v1.0 正式版前的发布候选，重点是将长篇续写工作流纳入稳定基线，并恢复完整发布门禁。

## 主要变化

- 新增长篇语料导入、Canon 事实库、分块索引与混合检索。
- 新增风格画像、故事线程、上下文编译、续写编排、checkpoint 和结果验证。
- 打磨工作区导航、Agent 作用域与集中修订流程。
- 修复 RC 独立复核发现的并发写入、质量刷新、统计与异步状态问题。
- 新增独立 Remotion 宣传片工程及 CI 门禁。
- 修复生产依赖审计问题。

## 兼容性

- 小说项目 `schemaVersion` 继续保持 `0.1.0`，已有项目无需迁移。
- Provider 密钥仍存储在操作系统安全存储中，不写入小说项目目录。
- RC2 仅提供 Windows x64 安装目标。

## 验证基线

- 格式、lint、类型检查和生产构建通过。
- 52 个测试文件、340 个用例通过。
- 桌面主进程 15 项 smoke 检查通过。
- `npm audit --omit=dev --audit-level=high` 为 0。
- 宣传片格式、lint/typecheck、生产依赖审计和 Remotion bundle 通过。
- Windows NSIS 安装包静默安装、启动存活与静默卸载通过，退出码均为 0。

## 分发说明

本候选版安装包尚未签名。测试者安装时可能看到 Windows SmartScreen 提示；正式版计划在代码签名证书和更新源就绪后发布。

Unsigned x64 安装包大小为 108,456,479 bytes；SHA-256 见同目录 `v1.0.0-rc.2-checksums.txt`。
