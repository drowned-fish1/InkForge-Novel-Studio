# InkForge v1.0.0-rc.4 发布说明

RC4 在 RC3 的桌面安全、导出保真与跨平台构建基础上，新增 EPUB 2/3 文稿导入。

## 新增

- 启动页可选择或拖入 `.epub`，并在创建项目之前预览章节、书名和作者。
- 支持 OPF 元数据、spine 阅读顺序、EPUB 3 NAV 和 EPUB 2 NCX 目录。
- 支持从单个 XHTML 正文中按 H1/H2 拆分多个章节。
- XHTML 安全转换为 Markdown：保留标题、段落、列表、引用、强调、代码和外部链接；图片降级为可读说明。
- 对损坏压缩包、缺失 OPF、异常条目数、过大解压体积和过大正文文件给出明确错误。

## 验证

- EPUB 解析器纯函数测试覆盖 EPUB 2、EPUB 3、spine 排序、章节拆分、安全转换和损坏文件。
- Playwright 真实上传 EPUB，验证元数据/章节预览、项目创建、章节树顺序和正文落盘，浏览器控制台 0 个错误。
- 全仓格式、lint、类型、54 个测试文件 / 353 个用例、16 项桌面 smoke、生产依赖审计和 Windows 打包均通过。
- 未签名 Windows x64 安装包为 108,781,948 bytes；SHA-256 见同目录 `v1.0.0-rc.4-checksums.txt`。

## 已知限制

- DRM 或加密 EPUB 不支持导入。
- EPUB 内嵌图片当前仅转成替代文本，不会复制进小说项目。
- 超大长篇仍使用一次性内存解析；流式、可恢复导入保留在后续性能路线图。
- Windows 安装包未签名；应用内更新仍需要代码签名证书和实际 HTTPS 更新源。
