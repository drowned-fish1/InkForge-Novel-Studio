# InkForge v1.0.0-rc.5 发布说明

RC5 把 InkForge 从单章写作与资料管理进一步整理成面向长篇迁移、连载管理和可审计 AI 协作的完整工作台。

## 新增

- DOCX、EPUB、Markdown 与多编码文本旧稿迁移，支持分卷拆章、乱码修正和创建前预览编辑。
- 整书人物／支线／视角矩阵；正文选区加入对话；最多六张跨章节固定资料卡。
- 每日写作模板、目标、待办、存稿排期与发布记录，以及 AI 人物卡和本地约束起名。
- 本书专属资料与来源原句校验、逻辑编辑、独立复核、续写记录分片存储和三流程对照工具。

## 整理与加固

- 抽取实体编辑、引用选择、编辑离开保护、项目搜索、写作工作区等共享模块，减少资料面板重复逻辑。
- Provider 按正文、规划、审阅和工具用途分别配置；安全存储、Token 预算和上下文窗口校验保持在主进程边界。
- 统一新增文档格式，并将 CI checkout/setup-node 升级到 Node 24 运行时兼容版本。

## 验证

- 格式、lint、Renderer/Electron 类型检查，以及 76 个测试文件中的 469 项单元／服务测试全部通过。
- 桌面主进程 16 项 smoke、主程序生产依赖高危审计、宣传片生产依赖零漏洞审计及 Remotion 打包全部通过。
- Windows x64 NSIS 安装包大小为 109,348,631 字节（104.28 MiB），SHA-256 为 `2f240f38b10bfe6d80ccecea30e9770d611fd2b66f35374d47fab617f618a42e`；完整清单见同目录校验文件。

## 已知限制

- Windows 安装包未签名，可能触发 SmartScreen；应用更新仍需要正式签名和 HTTPS 更新源。
- DOCX 解析依赖 Mammoth 的上游旧参数解析器仍有 3 项中危拒绝服务告警；当前没有不破坏 DOCX 导入能力的安全升级路径，高危门禁不受影响。
- 浏览器预览无法访问桌面项目内的相对图片，备份也是本地演示实现。
- AI 人物、逻辑审阅与正文质量仍取决于所配置模型，自动结果必须由作者判断。
