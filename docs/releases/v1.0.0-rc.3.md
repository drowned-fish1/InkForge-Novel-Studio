# InkForge v1.0.0-rc.3 发布说明

RC3 完成此前路线图中所有可在仓库内部落地的技术任务，重点是桌面安全、启动性能、导出保真和跨版本数据兼容。

## 主要变化

- renderer sandbox 已开启，preload 使用仅依赖 Electron 的 CJS bundle。
- 功能页按需加载，主入口约 310 KB；编辑器依赖拆分后无 chunk 超过 500 KB。
- DOCX/EPUB 嵌入项目内 PNG/JPG/GIF 正文图片。
- 旧名称引用自动补充稳定 ID，保留名称字段兼容旧版回滚。
- 浏览器 EPUB 支持完整元数据、版权页、分卷目录、NCX 和安全 Markdown。
- 自动更新接入口默认禁用，仅在正式包配置 `INKFORGE_UPDATE_URL` 后启用。
- CI 新增 macOS DMG/ZIP 与 Linux AppImage/DEB 工件。

## 仍需外部条件

- Windows/macOS 代码签名与 macOS notarization。
- 真实 HTTPS 更新源部署。
- macOS/Linux 原生 CI 首次构建和人工启动验证。

## 验证基线

- 格式、lint、类型检查与生产依赖审计通过。
- 53 个测试文件、349 个测试用例通过。
- 桌面主进程 16 项 smoke 通过；Windows unpacked 应用在 sandbox 下真实启动并持续存活 10 秒，stderr 为空。
- 未签名 Windows x64 安装包为 108,777,861 bytes；SHA-256 见同目录 `v1.0.0-rc.3-checksums.txt`。
