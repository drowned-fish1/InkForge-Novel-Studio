# UI 检查与修复记录 · 2026-10-11

本轮实际打开并检查了首页及全部 20 个工作区模块，保留现有小说写作工作台的视觉风格。修复重点是内容被挤压或裁切、窗口缩小时表单不可用、键盘操作与焦点管理，以及空状态正常但填入数据后出错的问题。

## 检查范围

- 浅色主题：全部 20 个模块分别检查 1440×1000、1024×1000、390×844，共 60 个场景。
- 深色主题：全部 20 个模块分别检查 1440×1000、390×844，共 40 个场景。
- 子面板：10 类新建表单、草稿箱 3 个标签、续写工程 5 个标签、检查工作台 5 个标签、章节辅助 5 个标签、备份设置、Agent 4 个辅助面板，在宽窗口和窄窗口共检查 66 个场景。
- 非空状态：长人物名、叙事三幕与节拍、Markdown 正文预览、质量报告、修订问题、备份列表与恢复前预览、首页导入预览。
- 首页导入预览额外检查两种主题及三种窗口宽度；质量评分卡片额外检查三种窗口宽度和卡片矩形是否重叠。
- 键盘、菜单、抽屉、删除弹窗和字数校验共完成 28 项交互断言。

窄窗口用于检查布局在空间不足时的行为，并不代表重新设计为手机应用。大纲分卷、叙事看板、编辑工具栏和标签栏保留有明确滚动区域的横向滚动。

## 全局修复

1. **按中间内容区宽度响应布局。** 原来仅按整个窗口判断，左右侧栏会让中间实际空间远小于窗口；使用命名容器查询让资料表单、续写、分支、批量生产等按实际可用空间调整。
2. **统一内容与滚动分配。** 资料库从固定两行网格改为纵向弹性布局，避免多个筛选条把列表和编辑器挤出视区；续写工作台与嵌套生产面板具有明确的滚动区域。
3. **完善顶部交互。** 文件与导出菜单互斥，点击外部和 Esc 可关闭；长名称提供提示；字号控制有名称与边界禁用状态；保存反馈区分已保存、保存中和失败。
4. **管理抽屉和弹窗焦点。** 窄窗口导航与 Agent 抽屉有模态语义、打开后聚焦、Tab 循环和关闭后焦点恢复；删除资料使用原生模态 dialog；错误读取引用后显示明确提示。
5. **完善键盘与辅助技术支持。** 可编辑大纲使用原生按钮；相关标签使用 tab 语义并支持方向键、Home、End；补齐可见输入与筛选器的名称；统一可见焦点环。
6. **完善主题与状态。** 补齐被组件引用但未定义的阴影、边框、成功、错误和警告变量，章节状态标记使用主题色；尊重减少动画设置。
7. **保持 Agent 输入可达。** 模型设置、运行控制、运行追踪和工作流互斥；辅助区域限制高度并可滚动，窄窗口打开设置时仍可访问消息输入框。

## 验证边界

视觉与交互检查运行于 Chromium 浏览器预览，使用隔离的“UI 检查样本”项目。Electron 原生文件选择窗口、操作系统窗口缩放，以及真实远端模型运行中的流式响应不在本轮浏览器检查覆盖范围内。导出页检查布局、配置和入口；不把它作为实际导出文件内容的验收。

工作区原有的后端、模型配置与其他业务改动予以保留。本轮未提交或推送代码。
