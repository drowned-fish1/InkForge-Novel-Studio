# Roadmap

> 状态：v1.0.0-rc.5 发布收口（2026-10-12）。
> v1 核心功能与长篇续写工作流均已实现；当前只处理正式发布门禁、分发和非阻塞技术优化。
> 详细实现记录与已知限制见 `docs/v1-implementation-status.md`。

## RC2 到 v1.0 正式版

1. **发布门禁**：格式、lint、类型、测试、桌面 smoke、生产依赖审计和 Windows 打包全部通过。
2. **安装包人工验证**：安装、升级、卸载、旧项目重开、无 Provider 离线流程、真实 Provider 提案与撤销。
3. **交付验证**：用至少两个阅读器验证 EPUB；确认 Markdown、TXT、DOCX 和备份恢复结果。
4. **公开分发**：代码签名证书和更新源就绪后接入 CI，创建 `v1.0.0` tag 与正式 Release。

代码签名和更新源是外部条件。在证书就绪前，可以发布明确标记“未签名”的 RC 预发布包，但不作为稳定版分发。

## RC3 已完成的内部技术任务

1. renderer sandbox：CJS preload 独立构建并启用 sandbox。
2. 页面级动态导入：主入口约 310 KB，大型编辑器/功能页按需加载。
3. 正文图片嵌入：桌面 DOCX/EPUB 支持项目内 PNG/JPG/GIF。
4. ID 化引用第一阶段：稳定 ID 镜像自动迁移，旧名称字段保留作为回滚路径。
5. 浏览器 EPUB 保真：补齐元数据、版权页、嵌套目录、NCX 与安全 Markdown。
6. 更新接入口：`electron-updater` 可配置状态机已接入，未配置时不联网。
7. macOS/Linux：构建配置与原生 CI 工件任务已接入。

浏览器真实磁盘备份、更新源部署、代码签名和目标平台人工启动仍属于外部环境或后续产品任务。

## RC4 已完成的内部技术任务

1. EPUB 2/3 导入：OPF 元数据、spine 顺序、EPUB 3 NAV 与 EPUB 2 NCX 均可解析。
2. 正文还原：XHTML 安全转换为 Markdown，单文件多 H1/H2 章节可拆分。
3. 安全边界：限制输入、解压总量、条目数和正文文件大小，过滤主动内容与无效页面。
4. 统一入口：桌面应用和浏览器模式共用同一解析器与既有项目创建流程。

## RC5 已完成的产品与整理任务

1. 旧稿迁移：DOCX、EPUB、Markdown、TXT、多编码读取、分卷拆章和创建前校正。
2. 长篇总览：人物／支线／视角矩阵、来源定位和 CSV 导出。
3. 写作上下文：选区加入 Agent 对话、跨章节固定资料卡和重名候选确认。
4. 连载管理：每日模板、目标待办、完稿估算、存稿排期与发布记录。
5. AI 分工：人物卡／起名、分用途 Provider、逻辑编辑、独立复核与本书专属资料。
6. 代码整理：抽取共享编辑器、引用、搜索、离开保护和持久化模块，更新 CI Action 与发布文档。

## RC2 基线

- 长篇续写：语料导入、Canon、分块索引、混合检索、风格画像、故事线程、上下文编译、续写编排与验证。
- 主应用：52 个测试文件 / 340 个用例，桌面主进程 15 项 smoke 检查。
- 安全：`npm audit --omit=dev --audit-level=high` 为 0。
- 宣传片：独立格式、lint/typecheck、生产依赖审计和 Remotion bundle 门禁。
- 分发：Windows x64 NSIS；安装包在签名证书接入前保持 unsigned。
