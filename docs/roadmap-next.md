# Roadmap

> 状态：v1.0 Release Candidate（2026-07-27）。
> 本文件原为 v0.x 阶段的开发路线图；其中列出的章节写作台增强、自动备份中心、草稿箱、
> 地点/势力/冲突/事件页面、集中修订工作台、Agent 授权与估算、EPUB 导出配置等条目
> 已在 v1.0 RC 全部实现。各阶段的实现记录、验证结果与已知限制见 `docs/v1-implementation-status.md`。

## v1.0 之后的候选方向

以下为有意推迟到 v1.0 之后的方向（非承诺）：

1. **ID 化实体引用**：当前跨实体引用是名字字符串（删除已有引用检查/解除/替换保护）；
   改为 ID 引用需要一次全量数据迁移。
2. **渲染进程 sandbox**：preload 目前以 ESM 产出，Electron 沙箱要求 CJS preload，
   需要独立的 preload 打包步骤。
3. **浏览器预览的导出/备份保真**：浏览器模式下 EPUB 生成与备份为降级演示实现，桌面版为完整实现。
4. **正文图片嵌入导出**：目前导出前检查会提示图片引用，EPUB 中退化为替代文字。
5. **应用内更新**：需要更新源与代码签名证书（外部条件），接入方案见 `docs/release-windows.md`。
6. **macOS / Linux 打包**：当前仅提供 Windows 目标。
