# 旧稿迁移与整书矩阵：开源复用记录

核对日期：2026-10-11。功能接入现有导入流程、章节大纲、人物库、场景规划、伏笔 / 冲突 / 时间线及续写剧情线；不增加另一份故事资料或矩阵存储。

## 已接入的行为

- DOCX / MD / TXT / EPUB 或文件夹迁移；中文分卷、章节，英文 Chapter 与文档标题识别；前言保留。
- 导入前选择编码 / 拆章规则，改标题 / 所属卷 / 正文，调整顺序，光标拆章，合并 / 移除；重新解析恢复源文件预览。
- 创建项目沿用现有流程，相邻同名卷合并，章节 ID 与全书章号保持唯一。
- 整书矩阵位于“剧情”导航，支持三个页签、卷 / 名称筛选、来源详情、打开章节 / 定位原文、CSV。
- 矩阵复用稳定 ID，兼容无 ID 的唯一姓名 / 别名；重复别名不猜测归属。归档章节排除，旧伏笔与已迁移剧情线去重。
- 场景规划可选视角人物和场景人物，无须由 Agent 写 JSON 后才能看到视角矩阵。
- 章节读取最多 8 个并行任务；失败显示具体提示。矩阵虚拟化使用库组件，筛选不重新扫描全文。

## 范围与限制

`.doc` 先另存为 `.docx`；页面排版、批注、修订记录和插图文件不迁移。Word / 文本单文件上限 64 MB；Word 解压总体积上限 256 MB，单条目上限 32 MB。EPUB 继续使用原有解析及限制。

矩阵是现有资料的派生视图。正文按姓名 / 别名精确匹配，不能可靠判断出场、代词指代或叙事视角；单字姓名容易误匹配。未标注的视角列为待补，不自动猜测。伏笔的“已解决”全局状态不意味着知道哪一章回收，只有具体回收证据才标回收。证据定位会重新查找源文本，避免直接按过时偏移选择错误内容。

预期回收窗口不计入剧情线推进或覆盖；间隔统计按全书章节关联计算，含末尾未关联章节，不含首次关联前的章节。记录缺失与故事实际缺席不是同一个结论。

`npm audit` 仍报告仓库既有依赖告警，以及 Mammoth CLI 的 argparse → sprintf-js 告警；CLI 不参与 renderer 的 Word 解析。此次没有运行全局 `audit fix --force` 或降级 Mammoth。XML 解析器已更新至修补版本。

## 验证

新增 12 项测试覆盖真实 DOCX 样式转换、旧编码、卷 / 章 / 前言 / 场景标题与代码块、错误文档、稳定 ID / 重复别名、归档排除、多视角和缺失视角、旧伏笔去重、预计回收区分、同一阶段的多个来源保留，以及 CSV 引号 / 公式保护。

- 桌面 renderer 与 Electron 类型检查通过；涉及的 TypeScript / JSX 与许可生成脚本 ESLint 通过。
- 全量测试：70 个文件、436 项通过；生产构建通过，许可文件确认进入 dist。
- 浏览器实际 DOCX / GBK TXT 导入与编码重试、标题与正文预览、重排 / 合并 / 重置 / 光标拆章 / 移除、两卷三章保存后正文核对通过。使用浏览器隔离测试项目，不修改作者的桌面小说项目。
- 浏览器矩阵验证：正文提及、来源详情、CSV 下载、卷 / 名称 / 关联筛选、未知视角、剧情线去重与预计窗口、原文定位、手动修改视角后持久化并在矩阵读取、键盘切换页签、深浅主题及 520px 窄窗无页面横向溢出通过。
- 2,000 章 × 120 个人物的模拟数据验证：同时读取上限 8；宽屏视口只渲染 132 个 gridcell、12 个列头和 12 行；可滚动到第 2,000 章和最后一行，冻结人物列保持位置，筛选末尾人物有效。模拟场景读取失败能显示提示，刷新后恢复。
- UI 工具的文件夹选择被拦截，因此浏览器测试使用既有本地存储降级；本轮没有验证系统目录选择、实际桌面安装包或付费模型调用。

截图与可复跑浏览器脚本在 `output/playwright/`，该目录由仓库忽略。新的复用依赖为精确版本；Mammoth 按需加载，矩阵独立懒加载。
