# 交互修复第二轮 · 2026-10-11

承接上一轮的两个后续优化点：资料引用搜索选择、全文搜索条目定位。修改与浏览器回归使用隔离样本小说，未操作用户的正式文稿。

## 已完成

| 原问题                                             | 修复后的行为                                                                                                                       |
| -------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 时间线、伏笔要手填章节 ID                          | 按章节名称或分卷搜索选择，展示章节名，实际保存章节 ID；关联可移除，旧的失效引用仍可见                                              |
| 人物、地点、势力靠输入名称，容易拼错或选错同名条目 | 时间线、伏笔、冲突、事件、地点、势力页使用可搜索选择器；人物支持别名搜索，同名条目显示身份说明；保留未建档名称的自定义入口         |
| 名称与关联 ID 不同步                               | 添加与移除时同时更新名称和 ID；已存在的名称引用、别名和未解析 ID 不会因为打开表单而被清空                                          |
| 保存链路把关联 ID 写成摘要文本                     | 浏览器保存与桌面规划导入的归一化处理保留人物、世界观、事件、伏笔中的 ID 字段，避免把这些字段当作额外正文                           |
| 候选列表影响键盘和窄窗口操作                       | 上下键选择、Enter 确认、Esc 收起；Tab 跳过候选列表；候选过多时提示缩小搜索范围；靠近编辑器底部时向上展开，并使用当前主题颜色       |
| 搜索命中资料后只打开模块                           | 精确选中人物、世界观、地点、势力、术语、伏笔、冲突、事件的目标条目；清除遮住目标的局部筛选；可匹配的文本字段获得焦点并选中匹配文字 |
| 搜索摘要看不到命中内容                             | 搜索标题与片段高亮关键词，长文本摘要截取命中附近内容；人物状态、世界观正文、冲突后果、伏笔回收等字段也进入搜索                     |
| 浏览器与桌面搜索范围不一致                         | 复用同一份纯搜索逻辑，两端搜索相同资料字段，章节最多展示三处正文命中                                                               |
| 快速搜索显示旧查询结果，失败无反馈                 | 新输入立即隐藏旧结果；延迟响应不能覆盖最新查询；显示加载、无结果、错误和重试入口；显示全部返回结果，移除原先只显示 30 条的静默截断 |
| 全文搜索与章节树筛选互相影响                       | 全文搜索、章节树标题筛选各有输入与状态；Esc 或清除按钮清空全文搜索                                                                 |
| 点击当前章节搜索结果覆盖未保存正文                 | 复用当前已加载正文，保持未保存状态；文字位置变化时重新寻找最近的同词匹配；目标已删除时提示重新搜索                                 |
| 取消跳转后残留定位指令、窄窗口导航误关闭           | 只有成功加载目标才设置章节定位并收起导航；资料搜索遵守未保存保护，取消后保留原输入                                                 |
